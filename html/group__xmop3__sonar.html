◆ sonar_echo_isr()

void IRAM_ATTR sonar_echo_isr ( void * arg)

FALLING-edge ISR: ECHO pin went LOW – echo received (or timeout on sensor side).

esp_timer_get_time() AND NOT micros(), AND THE FUNCTION BEING IRAM_ATTR IS WHY THAT MATTERS RATHER THAN WHY IT DOES NOT. An ISR marked IRAM_ATTR is placed in IRAM so it can run while the flash cache is disabled – but the marking covers THIS function only, not what it calls. Arduino's micros() lives in FLASH on this core (esp32-hal-misc.c; measured at 0x40170ba4 against esp_timer_get_time at 0x4008393c), so calling it from here jumped out of IRAM the moment a flash operation had the cache off, and the core panicked: 

Guru Meditation Error: Core 1 panic'ed (Cache error).
Cache disabled but cached memory region accessed

The backtrace comes out CORRUPTED, so the panic names neither this file nor the sonar – the only clue is the GPIO number sitting in A2/A4. Reproduced by (sd-mount) with a floating echo pin: esp_vfs_fat_sdmmc_mount disables the cache and the floating input supplies the edge. Any flash write will do it – LittleFS, NVS, OTA – so this is not SD-specific, and a board that has never mounted a filesystem can carry the fault indefinitely without showing it.

micros() is itself just (unsigned long) esp_timer_get_time(), so this is the same number with the same 32-bit wrap, and result()'s arithmetic is unchanged.

THE GENERAL FORM, worth carrying to any other ISR here: IRAM_ATTR places THIS function in IRAM and says nothing about its callees. An ISR is only as interrupt-safe as the deepest thing it calls.

< IRAM-safe; micros() is not

Sexpr_t Sonar_mop3_set_rest_after_echo_us ( Lamb & lamb,
Sexpr_t sexpr,
Sexpr_t env_exec )

(Sonar.rest-after-echo-us! <us>) – set the required REST measured from the ECHO (or from a declared timeout) to the next SEND; returns the effective value. 0 DISABLES it, leaving min-interval-us! the only gate. The default is NOT 0 – this gate is on; the value is SONAR_REST_AFTER_ECHO_DEFAULT_US. Never shortens min-interval-us!: both gates must pass, so this can only make the driver wait longer.
